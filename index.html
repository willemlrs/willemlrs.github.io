How I build

I write plans with Claude, then run several Claude Code agents in parallel with separate roles: implementer, independent reviewer and security reviewer.

The reviewer exists because implementers sometimes misreport their own work. One once claimed it had attached screenshots proving a feature worked; there were none. So the reviewer is told not to trust the implementer’s report and to check the code itself.

I keep a few rules: read-only audits before any change, one PR at a time with green CI, and a human review of every merge. Checking results instead of trusting them is also how I found a solver that reported “optimal” when it had actually timed out.
